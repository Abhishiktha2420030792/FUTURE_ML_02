# AI Support Ticket Classification & Prioritization System

## Overview
This project uses Machine Learning and NLP to automatically classify customer support tickets and predict their priority level.

## Features
- Text preprocessing
- TF-IDF vectorization
- Ticket type classification
- Priority prediction
- Streamlit web application

## Technologies Used
- Python
- Scikit-learn
- Pandas
- Streamlit
- NLP

## Dataset
Customer support ticket dataset from Kaggle.

## Workflow
1. Data preprocessing
2. Text cleaning
3. Feature extraction using TF-IDF
4. Model training
5. Evaluation
6. Deployment using Streamlit
